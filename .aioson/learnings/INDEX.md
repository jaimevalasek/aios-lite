# Project Learnings

- [Todo done-gate media o conteúdo do artefato; nenhum media se a entrega chegou ao git](gotchas/done-was-never-measured-against-git.md) — "pronto" e "entregue" divergiam em silêncio e o operador era o único detector; `delivery-parity` no `agent:done` (a chamada que todo agente já faz), `-uall` porque porcelain colapsa diretório novo em 1 entrada, churn de runtime nunca cobrado, advisory em todo tier; agrupar por área é o que torna o aviso acionável, e fatiar onda pós-fato é `git apply --cached` por hunk + `--fixup`/`--autosquash`

- [Um arquivo semeado pelo template carregava a forma do próprio framework](gotchas/template-seed-carried-the-frameworks-own-shape.md) — `design-doc.md` era o layout de CLI Node.js do aioson copiado em todo consumidor (project-local: `update` nunca corrigiria) e satisfazia o artefato de feature só por existir; retirar um seed = parar de embarcar **e** reconhecer a cópia antiga (`design-doc-seed.js`: `verbatim`/`derived`), seletor e engine recusam, `doctor --fix` apaga só a literal; 2ª ocorrência (28/08): presets de design fixos + `design-system/` + `premium-visual-design/` + refs órfãs = a forma do framework em todo consumidor → só a engine embarca, lista de ids nunca à mão no `src/` (teste varre o template), `doctor` nomeia `design_skill` aposentado
- [`system:publish --build` só protegia o que era compilado](gotchas/publish-build-shipped-runtime-typescript.md) — TS de runtime (`tsx server/*.ts`) viajava legível e um teste pinava isso; agora strip de tipos + terser sob o mesmo `.ts`, fonte cru derruba o publish, `--dry-run` lista o pacote, lixo de dev fica fora
- [O `$PWD` de um hook não é a raiz do projeto](gotchas/hook-cwd-is-not-the-project-root.md) — hooks descobrem a raiz subindo até um `.aioson/` **com entrada de projeto**; os que escrevem viram no-op fora de projeto e nunca criam store
- [Uma função passada ao `page.evaluate` não enxerga o módulo que a declarou](gotchas/page-evaluate-sees-no-module-scope.md) — sondas de browser recebem tudo por argumento; a suíte re-executa a sonda serializada num realm isolado e o Playwright resolve do projeto primeiro (`playwright-loader`)
- [Arquivo rastreado sob regra de `.gitignore` faz `git add -- <caminho>` recusar tudo](gotchas/tracked-but-ignored-files-break-git-add.md) — stage em duas faixas (`add -u` para rastreados), erro do git sem o ruído de LF/CRLF, `trackedIgnored` medido em update/setup/commit:prepare; e o detector de segredo aprende descritor, locale no basename e símbolo sob `token`
- [Renomear um agente é declarar `legacyIds` uma vez — não um sed](recipes/renaming-an-agent-id.md) — `aliases` = stub vivo, `legacyIds` = nome antigo sem arquivo; `canonicalAgentId()` em todo lookup por id; migração no `update` apaga os arquivos do nome antigo; prova = regra do cliente com o id antigo ainda bate no novo
- [Uma superfície de browser real entra pelo resolvedor, é testada com página fake e só vale como evidência quando um gate a lê](recipes/adding-a-real-browser-surface.md) — `openBrowser()` (CDP → Chrome/Edge instalado → empacotado) em todo comando de browser; runner testado com `Page` fake + live-fire nos 3 modos; flag bare do help entra em `BOOLEAN_FLAGS`; evidência só conta em `features/{slug}/browser/` (protótipo nunca é AC)
- [O caminho orquestrado só perguntava depois de destravado — e nada o destravava](gotchas/orchestrated-path-had-no-first-door.md) — o gate media destravamento, nunca escala: `plan-scale` mede o plano e um candidato a divisão ganha a pergunta esteja o arquivo de papéis lá ou não; `execution:seed` semeia desligado, `onboarding.next` nomeia o passo, `[Execution Scale]` cobra a resposta registrada; leitor do cliente recusa chave de raiz nova → estado irmão
