# Profiler Trait and Method Analysis

Load for the main extraction pass after the evidence ledger exists.

## Decision frameworks

For every named or repeated framework, capture:

- name and `named`, `adapted`, or `inferred`;
- origin when borrowed;
- inputs, ordered process, outputs;
- application context;
- decision points and failure conditions;
- source IDs and confidence.

Do not turn a slogan into a framework without repeatable steps.

## Communication

Analyze only evidenced patterns:

- dominant tone/register and audience variation;
- sentence/paragraph tendencies and vocabulary;
- story/data balance, metaphor, humor, or profanity;
- assertiveness and certainty markers;
- persuasion structure and recurring expressions;
- changes under disagreement or pressure.

Separate written, spoken, edited, and spontaneous material when they differ.

## Values and expertise

Extract non-negotiable values, operating beliefs, priority hierarchy, time horizon, demonstrated mastery, shallow-opinion zones, decisions/outcomes, and intellectual influences. What the subject teaches, does, and rewards may differ; preserve the distinction.

## Biases and blind spots

Identify repeated error patterns, over/under-confidence zones, incentive effects, criticism from credible peers, and compensatory behavior. A single controversy is not a recurring bias.

## Operational method

This is the highest-value output for downstream genomes. Extract:

1. **Procedure:** named or reconstructed ordered steps, with inputs, actions, decisions, and outputs.
2. **Output structure:** sections, sequence, and proportions only when evidenced.
3. **Style metrics:** measurable, repeatedly observed rules.
4. **Prohibitions:** explicit or strongly demonstrated “never do X” constraints.
5. **Delivery checklist:** checks the subject uses before shipping.

Each item cites source IDs. Mark reconstructed procedures `inferred` and explain the reconstruction. If no method is documented, state the gap; do not convert general philosophy into fake procedure.

## Analysis pass

Produce provisional claims from the source ledger, then run one contradiction pass:

- search already-loaded evidence for disconfirming examples;
- distinguish persona, role, audience, and time period;
- delete unsupported precision;
- reduce confidence or retain competing hypotheses.

Do not browse in this phase. Missing evidence becomes a concrete Researcher follow-up query.

## Downstream consequences

For each supported item, state whether it should affect:

- genome procedure or decision weights;
- restrictions/prohibitions;
- checklist/quality gate;
- communication style;
- output structure;
- advisor challenge behavior;
- known limitations.

Only evidence-backed consequences enter the Generation Handoff.
