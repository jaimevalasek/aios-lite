# Bold Editorial UI

Let typography establish architecture and contrast establish rhythm. Build an authored composition, not a generic marketing template. Never combine it with another design skill.

## Workflow

1. Confirm explicit selection; do not infer from “premium” alone.
2. Load `references/art-direction.md` and choose one expression.
3. Load `references/design-tokens.md` for every surface.
4. Load only the task-specific references below.
5. Implement in the active stack with semantic heading order, keyboard access, responsive type, reduced motion, and accessible contrast.
6. Validate narrative pacing and conversion clarity before handoff.

## Reference routing

| Scope | Additional references |

| Reusable components | `references/components.md` |

Load all seven references only when the task spans the complete system.

## Non-negotiable signature

- Use an intentional display/body type relationship and a clear editorial scale.
- Compose with asymmetry, cropping, whitespace, rules, and contrast—not a repeated card grid.
- Keep one dominant visual or typographic idea per viewport.
- Use motion to support sequencing and reveal; honor reduced-motion preferences.
- Keep conversion actions and navigation obvious despite expressive composition.
- Adapt the system to content; do not fill space with invented marketing claims.

## Quality gate

Reject the result if it resembles a generic hero-plus-three-cards template, every heading is oversized, layout drama breaks reading order, type wraps poorly, motion blocks content, contrast is decorative rather than functional, or mobile loses the narrative hierarchy.
