# Warm Craft UI

Create confidence through clarity, humane typography, breathing room, soft geometry, and restrained warmth. Never combine it with another design skill.

## Workflow

1. Confirm explicit selection; do not infer from “clean” alone.
2. Load `references/art-direction.md` and select an expression mode.
3. Load `references/design-tokens.md` for all UI work.
4. Load only the references needed for the requested surface.
5. Implement in the active stack with semantic markup, accessible contrast, keyboard behavior, responsive composition, and clear states.
6. Validate warmth without sacrificing density or task efficiency.

## Non-negotiable signature

- Use warm neutrals and one restrained accent family; avoid sterile blue-gray defaults.
- Use generous but purposeful whitespace, with tighter density inside data-heavy controls.
- Favor humanist typography, clear hierarchy, rounded forms, and subtle depth.
- Keep copy direct and reassuring without becoming childish.
- Use motion for continuity and feedback, not decoration.
- Preserve readable contrast and unmistakable focus in light and optional dark themes.

## Quality gate

Reject the result if it becomes generic pastel SaaS, spacing wastes task area, rounding is applied indiscriminately, warmth lowers contrast, illustrations overpower the product, controls lack clear states, or mobile removes critical context.
